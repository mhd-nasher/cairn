# Cairn — Brand Assets

Drop the two brand images here with these exact names:

| File | What it is | Recommended size |
|------|-----------|------------------|
| `cairn-icon.png` | The square cairn mark (stones + guide-light) | 512×512 (square, transparent or dark bg) |
| `cairn-banner.png` | The wide banner: cairn + "Cairn" + tagline | ~1280×640 (2:1) |

Usage:
- `cairn-banner.png` → embedded at the top of the main `README.md`, and uploaded as the repo's
  **Social preview** in GitHub → Settings → General → Social preview.
- `cairn-icon.png` → use as the GitHub profile/org avatar and as a favicon source.
